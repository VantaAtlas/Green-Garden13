## 本版确认尺寸

| 项目 | 尺寸（mm） |
| --- | --- |
| 墙体高度 | 950 |
| 主窗高度 | 1490 |
| 主窗上部型材及固定玻璃带 | 60 |
| 整套窗总高 | 1550 |
| 墙加整套窗 | 2500 |
| 正面窗宽 | 2720 |
| 侧窗长度 | 1350 |
| 侧窗南北斜边高差 | 90 |
| 长城板 | 3220 × 3020 × 50（宽长单位待现场核对） |
| 水平吊顶厚度 | 50 |

东西两侧同高。暂按正面朝北、南高北低排水。吊顶底与主窗顶齐平，距地2440 mm；厚50 mm，北端与长城板底净空约60 mm，向南增大。室内封边遮住顶部60 mm及东侧斜边玻璃带。西侧为实墙无玻璃，东侧保留窗。新增朝北的屋内视角。

页面提供旋转、缩放、正/侧/俯视、推拉演示以及屋顶、吊顶、墙体显隐。
这是空间尺寸沟通示意，不包含加工级型材、玻璃净尺寸、吊杆、防水及结构节点；施工前需现场深化。
