# 格林花园餐厅 · V08

在线查看：https://vantaatlas.github.io/Green-Garden13/v08.html

- 正面4扇等分双轨移窗，东侧2扇等分双轨移窗，支持分别开合。
- 墙950 mm；主窗1490 mm；顶部60 mm纯铝合金型材（无玻璃）；整窗1550 mm。
- 主窗与上部共用连续一体外框，进深110 mm。
- 西侧整面实墙，无玻璃、无窗框；东侧斜边为固定型材收口。
- 吊顶厚50 mm，与长城板同坡度、平行分离，净空暂定60 mm；北窗内侧退让200 mm预留纱帘槽。
- 纱帘轨道示意固定于长城板下方，屋内视角可查看。
- 正面宽2720，侧窗长1350，侧窗南北高差90 mm。长城板3220 × 3020 × 50 mm，宽长单位待现场核对。

仅为施工沟通示意，窗扇加工宽度、轨道承载、防水和型材收口需施工方深化。
