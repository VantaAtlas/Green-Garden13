# 格林花园餐厅 · V09

在线查看：https://vantaatlas.github.io/Green-Garden13/v09.html

- 西侧墙体中段加入约600 mm宽固定玻璃，其余保持墙体。
- 正面4扇等分双轨移窗，东侧2扇等分双轨移窗。
- 屋内视角默认朝北，西侧玻璃显示在左侧；室内支持拖动移动与滚轮缩放。
- 主窗与顶部60 mm纯铝合金型材共用110 mm进深一体窗框。
- 吊顶厚50 mm，与长城板同坡度，预留纱帘安装位置。
- 墙950 mm；主窗1490 mm；整窗1550 mm；正面宽2720；侧窗长1350。

仅为施工沟通示意，西侧玻璃开洞尺寸、边框、轨道承载、防水和收口需施工方深化。
