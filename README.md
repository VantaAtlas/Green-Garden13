# 格林花园餐厅 · V14

在线查看：https://vantaatlas.github.io/Green-Garden13/v14.html

- 侧面按参考图表现为下部2扇移窗，上部G7斜固定玻璃。
- G7斜玻璃颜色已与其他玻璃统一。
- 正面与东侧玻璃均配纱帘，窗帘高度按1480 mm示意；东侧轨道沿长城板坡度布置。
- 北侧窗内侧增加西餐厅吧台示意，含木质台面、柜体和三张高脚凳。
- 西侧整面实墙无窗；正面4扇等分双轨移窗。
- 屋内视角默认朝北，支持拖动移动与滚轮缩放。
- 一体窗框进深110 mm；顶部纯铝合金型材60 mm。
- 吊顶厚50 mm，与长城板同坡度，预留纱帘安装位置。

仅为施工沟通示意，吧台尺寸、动线、给排水/电位、斜玻璃高度、开洞尺寸、轨道承载、防水和收口需施工方深化。
